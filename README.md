# neXsv — Repositorio de publicación

Este repositorio contendrá únicamente los archivos necesarios para desplegar la versión pública de neXsv. El proyecto maestro, la documentación interna y las migraciones se conservan en el repositorio privado `neXsv_master`.

La publicación de GitHub Pages y el dominio de producción no deben configurarse aquí hasta completar las pruebas y autorizar el cambio.
